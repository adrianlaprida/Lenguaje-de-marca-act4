Actividad 01: Modelo de Cajas

En esta actividad trabajamos el modelo de cajas de CSS, aprendiendo cómo se organiza el espacio de los elementos de una página web.

El modelo de cajas está compuesto por cuatro partes: contenido, padding, border y margin.

En esta actividad aprendimos a utilizar Flexbox para organizar y distribuir elementos dentro de un contenedor.
